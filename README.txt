91 SPEED SHOP DEMO v1.0
========================

Files:
- index.html: interactive demo interface
- 91-speed-shop-logo.png: exact logo supplied by the user

Includes:
- No-login demo dashboard
- Lighting controller simulation
- AI Pixel Studio local image-to-pixel preview
- Custom LED grid dimensions
- Air suspension simulation
- Drag controller simulation
- ECU/Dyno sample display
- Sound Sync demo screen

Important:
This is a web demo project, not a compiled APK.
The controls are local simulations and are not connected to Roblox/A-Chassis.
The supplied logo is included and displayed in the app header. Use it as the launcher icon
when configuring the Android wrapper/build service.
